# ⏱️ TimeWorking by ChrizDev
### *Precisión, Honestidad y Control Total del Tiempo Laboral*

![TimeWorking Logo](assets/app_icon.png)

**TimeWorking** no es solo un temporizador; es una suite administrativa premium diseñada para el sector agrícola y la gestión de jornadas independientes. Desarrollada por **ChrizDev**, esta aplicación garantiza que cada segundo trabajado sea valorado y cada pago sea justo.

---

## 💎 Características Elite

### 🌑 Interfaz "Black Elite"
Diseño minimalista con modo oscuro profundo, acentos en verde esmeralda y oro, optimizado para largas jornadas y uso profesional en campo.

### ⏱️ Cronómetro Persistente con Lógica de Servidor
El tiempo nunca se detiene. Gracias a la integración con Supabase, el contador se mantiene sincronizado aunque cierres la app, reinicies el móvil o se agote la batería.

### 📄 Reportes PDF Profesionales
Genera desgloses detallados compatibles con cualquier plataforma de mensajería (WhatsApp, Email) para facilitar el cobro semanal con el capataz.

### 💰 Lógica de Pago Avanzada
*   **Tarifa**: $6.000 COP / Hora.
*   **Regla del Sábado**: Lógica inteligente que excluye el sábado actual del reporte semanal para asegurar el flujo de caja en la semana siguiente.
*   **Historial de Facturas**: Registro histórico de cada semana pagada con notas administrativas.

## 🛡️ Seguridad y Control de Administración

La aplicación está blindada para proteger la cuenta del usuario y los intereses del administrador:
*   **Registro Protegido**: Solo realizable mediante Clave de Administrador.
*   **Cierre de Sesión Blindado**: Requiere autorización de ChrizDev para evitar cambios de perfil no autorizados.
*   **Reset Maestro**: Función exclusiva para limpiar historiales mediante clave de seguridad.

*   **Despliegue**: Optimizado para Vercel (PWA) e Instalable en móviles.
